# Linux에서 공유하기

첫 지원 대상은 **Ubuntu 24.04 LTS amd64의 로그인한 X11 데스크톱**입니다. Mac의 `Linux 화면` 또는 Windows의 `Linux 열기`에서 접속합니다. Linux 클라이언트·파일 전송·Wayland·로그인 화면·헤드리스는 아직 지원하지 않습니다.

1. 배포된 `DeskBridge-버전-ubuntu24.04-amd64-preview.deb`를 Ubuntu 패키지 설치 프로그램에서 여세요. 그래픽 설치기가 없다면 다운로드 폴더에서 `sudo apt install ./실제파일명.deb`로 설치합니다. `실제파일명`은 받은 파일의 정확한 이름으로 바꾸세요(직접 빌드/CI 산출물은 `DeskBridge-Linux.deb`). 데스크톱 앱 목록의 **DeskBridge Linux Host**를 엽니다.
2. 로그인 화면에서 사용자를 선택하고 톱니바퀴의 **Ubuntu on Xorg**로 로그인하세요. 앱의 **공식 Sunshine 받기**로 정확한 버전의 패키지를 받고 **시스템 설치 프로그램으로 열기**를 선택합니다. 기본 설치기가 `.deb`를 처리하지 않으면 **검증된 설치 패키지 사본 저장…**으로 다운로드 폴더 등에 저장하세요. 사본 저장 후 앱에 표시되는 정확한 `sudo apt install …` 명령을 터미널에서 직접 실행할 수 있습니다. 앱은 명령을 실행하지 않습니다. 다른 버전은 자동으로 제거하거나 교체하지 않습니다.
3. Sunshine 앱이나 사용자 서비스를 따로 시작하지 마세요. 기존 Sunshine이 있다면 직접 종료하고, 이미 자동 시작하도록 설정했다면 그 설정도 직접 확인하세요. 공식 Sunshine 패키지가 udev의 세션별 입력 권한을 제공합니다. 입력 권한 오류가 나면 로그아웃·로그인 또는 재부팅 후 다시 시도하세요. DeskBridge는 `input` 그룹 가입이나 임의 장치 권한을 부여하지 않습니다.
4. 최초 실행 시 앱의 웹 관리자 이름과 16~128바이트 비밀번호를 입력하고 **이 Linux 공유 시작**을 누릅니다. 네트워크 포트를 열기 전에 무작위 salt와 비밀번호 해시를 원자적으로 준비합니다. 기존 계정은 자동 변경하지 않으며 손상된 계정 파일은 시작을 거부합니다. **이 컴퓨터의 Sunshine 웹 설정 / PIN 열기**에서 이 계정으로 로그인합니다. URL은 `https://localhost:47990`입니다. 자체 서명 인증서 안내가 나오면 이 컴퓨터의 주소를 직접 확인하세요. 관리자 비밀번호는 QR에 넣지 않습니다.
5. **내 주소와 연결 QR 만들기**를 누릅니다. Mac의 `Linux 화면` 또는 Windows의 `Linux 열기`에서 검색·QR 이미지·링크 중 하나로 주소를 선택하세요. 같은 모니터를 쓰면 QR PNG 파일이나 링크를 옮기는 방법이 편합니다. Tailscale에서는 양쪽이 이미 연결돼 있어야 합니다. QR의 OS 표시는 신원 증명이 아닙니다.
6. 클라이언트의 PIN 연결을 시작하고 이 Linux의 Sunshine PIN 페이지에서 승인합니다. 페어링 후 Desktop을 여세요. 화면·키보드·마우스·오디오는 실제 연결에서 확인합니다. 프로세스 실행 상태는 영상 성공을 뜻하지 않습니다.

같은 Wi-Fi에 여러 Sunshine 기기가 검색될 수 있습니다. 검색 메타데이터만으로 운영체제나 기기 신원은 확인되지 않습니다. 직접 PC를 선택하세요. 앱을 닫거나 공유 중지를 누르면 앱이 실행한 프로세스 그룹만 종료하고 기존 Sunshine 프로세스는 건드리지 않습니다. 별도 감독 프로세스는 앱 전용 수명 파이프가 닫히면 자신의 공유 그룹을 종료합니다. 커널에서 종료를 완료하지 못하면 창은 실패 안내와 재시도 기능을 유지합니다. 실제 실행 상태도 확인하세요.

방화벽은 자동 변경하지 않습니다. 신뢰하는 LAN/Tailscale 인터페이스에서 Sunshine의 기본 포트를 허용하세요(TCP 47984/47989/47990/48010, UDP 47998–48000/48002/48010; 최신 upstream 문서도 확인). 인터넷 포트 포워딩은 하지 마세요. 관리 웹 UI는 `origin_web_ui_allowed=pc`로 제한합니다. 이는 OS 방화벽을 설치하거나 라우터 설정을 검증한다는 뜻은 아닙니다.

앱은 공식 Sunshine 2026.914.233613의 Ubuntu 24.04 amd64 패키지 크기/SHA256과 설치된 바이너리 SHA256을 확인합니다. 공식 패키지 설치는 시스템 권한·udev 규칙·파일 capabilities를 설정하는 upstream 동작입니다. DeskBridge는 X11 캡처만 사용하며 `setpriv --no-new-privs`로 Sunshine 실행 시 파일 capabilities를 통한 권한 상승을 막습니다. LAN/WAN 암호화를 필수로 고정하고 UPnP·컨트롤러를 끕니다. 캡처·인코더·오디오 하드웨어 호환성은 별도 기기 테스트가 필요합니다. Chrome 원격 데스크톱보다 빠르거나 안전하다는 비교 결과는 아직 없습니다.

설정과 페어링은 사용자 전용 `~/.local/share/deskbridge-linux-v1/`에 보관합니다. 기존 Sunshine 설정·로그를 가져오지 않습니다. 웹 설정에서 캡처/보안을 바꿔도 앱이 시작할 때 필수 정책을 명령행으로 덮어씁니다. 앱 삭제는 `sudo apt remove deskbridge-linux-host`로 할 수 있으며, 사용자 페어링/설정과 별도 Sunshine 패키지는 보존합니다. 설정 초기화는 인증서를 바꾸므로 연결 상대를 확인한 뒤 사용자가 직접 결정하세요.

DeskBridge는 GPL-3.0-only입니다. Sunshine(GPL-3.0)은 별도 공식 패키지로 받고, GTK/PyGObject·python-qrcode·Pillow는 Ubuntu 패키지 의존성으로 설치됩니다. 각 패키지의 저작권·라이선스는 `/usr/share/doc/<package>/copyright`를 확인하세요. DeskBridge의 소스와 빌드 도구는 함께 제공됩니다. 서명된 공개 APT 저장소·자동 업데이트는 제공하지 않습니다.

저장소 복구: 모든 DeskBridge Linux 창과 이 앱이 실행한 공유를 종료한 뒤 `~/.local/share/deskbridge-linux-v1/` 전체를 별도 위치에 백업하세요. `.owner`가 없거나 권한/하드링크 검사에 실패한 폴더는 자동 채택하지 않습니다. 페어링을 유지하려면 원본 전체와 소유자·권한을 전문가와 확인하세요. 초기화가 필요하면 기존 전체 폴더를 보존한 채 다른 이름으로 옮기고 앱을 다시 열 수 있으나, 새 인증서가 만들어지므로 클라이언트에서 신원을 다시 확인하고 명시적으로 재페어링해야 합니다.

다운로드 복구: 기존 다운로드 검증 오류라면 앱을 닫고 위 폴더의 `downloads/sunshine-버전-ubuntu24.04-amd64.deb` 중 오류가 난 고정 버전 파일만 별도로 보존하거나 다른 이름으로 옮기세요. `credentials`, `state.json`, `web-credentials.json`과 나머지 설정은 건드리지 마세요. 앱을 다시 열고 **공식 Sunshine 받기**를 선택합니다. 프로그램은 기존 파일을 자동 삭제하거나 덮어쓰지 않습니다.

이전 preview.12 이하에서 공유를 사용했다면 업그레이드 후 Sunshine 웹에 본인이 정한 관리자 계정으로 로그인되는지 확인하고 페어링된 기기 목록을 검토하세요. 기존 계정·페어링은 자동으로 교체하거나 초기화하지 않습니다. 모르는 계정이거나 로그인할 수 없다면 공유를 중지하고 전체 설정을 백업한 뒤 신원과 복구 방법을 확인하세요.
