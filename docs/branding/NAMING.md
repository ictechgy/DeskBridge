# Knot

Status: **Selected by the user, 2026-10-22.** The project formerly used DeskBridge. The public product name is now **Knot**, including in the Korean interface.

A knot ties separate strands together. The proposed brand story is that Mac, Windows and Linux remain separate computers while becoming part of one working environment. The name is independent of any OS, transport or engine.

**Your computers, tied together.**

한국어 설명: **컴퓨터를 잇다. 작업을 이어가다.**

## Symbol

Two interwoven loops form the app mark, using the existing ink/ivory/teal palette. The loops represent connection; they do not imply audited security, a mesh-network service, file synchronization or measured performance. Geometry and native icon generation are documented in [LOGO.md](LOGO.md).

## Existing uses and scope

Knot is an ordinary English word and is already used by unrelated software, including a [development-workspace tool](https://getknot.dev/) and a [Mac utility](https://baomi.app/knot). This project is independent of those products. The user selected the name after those uses were disclosed. The selection does not establish trademark, domain, package-name or other exclusive rights.

The source remains GPL-3.0-only. Preserve upstream copyright and license notices. Compatibility identifiers retain the former name where changing them could discard saved trust or break an upgrade; see [Brand compatibility](../BRAND_COMPATIBILITY.md).
